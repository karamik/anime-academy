# Чек-лист первого плейтеста

## Подготовка

1. Скачай `game.rbxlx` из GitHub или получи через `rojo serve`.
2. Открой в Roblox Studio.
3. Убедись, что установлен плагин **Rojo** (если работаешь через serve).
4. Нажми **Play** (F5), не **Run** — нужен полноценный клиент.
5. Открой **Output** (View → Output). Там будут все ошибки.

## Порядок проверки

Идём от простого к сложному. Если на шаге N что-то падает — фиксируй и **не переходи дальше**, пока не починишь.

### 1. Загрузка сервера
- [ ] Игра запускается без красных ошибок в Output.
- [ ] В Output есть `[Хроно] Подключился: <твой ник>`.
- [ ] В Output есть `[DataStore] Загружено для <твой ник>`.
- [ ] В Workspace видны: `HubFloor`, `RaidFloor`, `Bridge`, `GachaAltar`, `UpgradeAltar`.

### 2. Спавн и Хаб
- [ ] Игрок появляется на спавне в центре хаба (не падает в пустоту).
- [ ] Стены хаба стоят, игрок не проваливается.
- [ ] В левом верхнем углу виден HP-бар (100/100).
- [ ] Под HP-баром видна шкала Глитча (фиолетовая, пустая).
- [ ] В правом верхнем углу видны «Кредиты: 0» и «Глитч-код: 0».
- [ ] Слева снизу видна кнопка «ВЗЯТЬ КВЕСТ».
- [ ] На телефоне (эмуляция) справа снизу есть круглая кнопка «АТАКА».

### 3. Алтарь гачи
- [ ] Подойди к фиолетовой неоновой плите справа (GachaAltar).
- [ ] При касании в Output появляется `[Гача] Игрок <ник> получил <оружие>`.
- [ ] В инвентаре (Backpack) появляется Tool с названием оружия.
- [ ] Оружие можно экипировать (нажать на слот).
- [ ] В чате появляется реплика оружия (например, «Не спи, нас сожрут!»).

**Если оружие не появляется в руке** — проблема с `Tool` без `Handle`. Это известный риск. Решение: добавить невидимый Handle в `createTool`.

### 4. Переход в рейд
- [ ] Нажми кнопку «ВЗЯТЬ КВЕСТ».
- [ ] Игрок телепортируется на арену (позиция ~100, 5, 0).
- [ ] В Output появляется `[Raid] Дроны зачищены. Спавн босса...` (после убийства).
- [ ] Шкала Глитча начинает расти (виден фиолетовый заполняющийся бар).

### 5. Бой с дронами
- [ ] На арене появляются 5 фиолетовых дронов.
- [ ] ЛКМ (или кнопка АТАКА) наносит урон.
- [ ] HP дрона уменьшается, при 0 — дрон исчезает.
- [ ] За каждого дрона растут кредиты (проверь в HUD).
- [ ] После убийства 5 дронов — спавнится босс.

**Если атака не работает** — проверь, что Tool экипирован, и что в Output нет ошибок от `CombatHandler`.

### 6. Бой с боссом

**Если выпал Нюкс** (жёлтый):
- [ ] Босс появляется в центре арены.
- [ ] Босс телепортируется каждые 3–5 секунд.
- [ ] Свет периодически тускнеет на 3 секунды.
- [ ] При 60% HP (4800) появляется щупальце с уроном.

**Если выпал Локус** (синий):
- [ ] Босс появляется в центре арены.
- [ ] Босс телепортируется чаще (каждые 2–3 секунды).
- [ ] Босс стреляет синим лучом.
- [ ] При 50% HP (1500) начинается фаза 2 (в Output `[Локус] Фаза 2`).
- [ ] При 30% HP (900) начинается фаза 3 (в Output `[Локус] Фаза 3`).
- [ ] Сфера маленькая и быстро телепортируется.
- [ ] Через 20 секунд — либо взрыв, либо убийство босса.

### 7. Завершение рейда
- [ ] После смерти босса в Output: `[Босс] ... побеждён` или `[Локус] ... побеждён`.
- [ ] В HUD появляется уведомление «Рейд пройден!».
- [ ] Кнопка квеста возвращается в состояние «ВЗЯТЬ КВЕСТ».
- [ ] Игрок телепортируется обратно в хаб.
- [ ] Шкала Глитча обнуляется.

### 8. Алтарь апгрейда
- [ ] Подойди к золотой неоновой плите слева (UpgradeAltar).
- [ ] Если кредитов хватает (200+) — оружие прокачивается.
- [ ] В Output: `[Апгрейд] <ник> поднял <оружие> до ур.2`.
- [ ] Кредиты списываются (проверь HUD).
- [ ] Урон оружия растёт.

**Если апгрейд не срабатывает** — проверь, что кредитов >= 300 (цена 1→2).

### 9. Сохранение
- [ ] Выйди из игры (Stop в Studio).
- [ ] Запусти снова (Play).
- [ ] Кредиты, глитч-код, оружие и уровни на месте.
- [ ] Экипировка сохраняется.
- [ ] Позиция сбрасывается в хаб (это правильно).

**Если данные не сохраняются** — DataStore в Studio работает только при включённой опции **Enable Studio Access to API Services** (Game Settings → Security).

## Известные вероятные проблемы

1. **Tool не экипируется.** У Roblox `Tool` без `Handle` иногда не отображается. Решение: добавить невидимую часть Handle в `WeaponSystem.createTool`.

2. **Луч Локуса не попадает.** `Raycast` может задеть самого босса. Мы исключили его в `FilterDescendantsInstances`, но проверить надо.

3. **Сфера самоуничтожается и убивает всех.** Если команда не успевает — это норма. Но если убивает **через стены**, радиус `selfDestructRadius = 10` слишком большой, уменьшить.

4. **Дроны не двигаются.** Мы не писали `MoveTo` — они статичны. Это ожидаемо. Если нужно движение — добавим.

5. **Боссы не атакуют игроков.** Нюкс бьёт щупальцами только в фазе 2. Локус бьёт лучом. Если этого мало — добавим больше атак.

6. **Шкала Глитча в HUD не связана с сервером.** Сейчас она растёт локально. В следующей итерации нужно синхронизировать через RemoteEvent.

7. **DataStore не работает в Studio без API Services.** Включи в Game Settings.

## Как фиксировать результат

После плейтеста заполни:

- Что работает: (список)
- Что не работает: (список)
- Что бесит: (список)
- Что скучно: (список)
- Скриншоты багов: (папка)

Сохрани это в `NOTES.md` и коммить. При следующей правке — идти по списку.

## Что делать после плейтеста

1. Починить критичные баги (игра падает, ничего не работает).
2. Починить баланс (слишком легко / слишком сложно).
3. Отложить красивости (графика, анимации) — они не про геймплей.
4. Записать видео прохождения — для TikTok/Shorts.
5. Пригласить 2–3 друзей — второй плейтест с реальными людьми.
